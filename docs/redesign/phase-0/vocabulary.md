# Product vocabulary

Use these labels in designs and future UI migrations. Existing runtime copy remains unchanged until the relevant implementation phase.

| Concept | Approved term | Usage rule |
| --- | --- | --- |
| Product | **NetQuest** | Replace “Net Study” only when the owning surface is migrated. Never vary the logo wordmark. |
| A playable activity | **Mission** in discovery/progression UI; existing proper game name in titles | “Choose a mission,” then “Port Number Game.” Do not use challenge/game/mission interchangeably in the same control group. |
| Replaying | **Play again** | Primary result action. |
| Leaving results | **Choose another mission** | Secondary result action; destination is the dashboard/library. |
| Configuration style | **Mode** | Current values remain **Time Attack** and **Practice**. |
| Complexity | **Difficulty** | Current values remain **Easy**, **Medium**, and **Hard**. |
| Earned progression currency | **XP** | Uppercase; format as `+120 XP` when earned and `1,240 XP` as a total. |
| Consecutive correct answers | **Answer streak** or **streak** in a game | Do not confuse with the daily learning streak. |
| Consecutive active days | **Day streak** | Always include “day” near the value outside a dedicated streak view. |
| Progression tier | **Level** | Format as `Level 4`; titles such as “Network Specialist” are supporting labels. |
| Structured curriculum | **Learning path** | A path contains modules; a module contains lessons. |
| Curriculum unit | **Module** | Preserve numbered/title identity. |
| Reading unit | **Lesson** | Use **Start lesson**, **Continue lesson**, and **Review lesson** by state. |
| Lesson validation | **Knowledge check** | Avoid switching to “quiz” in learner-facing copy within the lesson. |
| Earned badge | **Achievement** | Use **Achievement unlocked** for the event. |
| No account | **Guest** / **Guest mode** | Main save prompt: **Sign in to save progress**. |
| Main landing CTA | **Start as guest** | Replaces “Explore as Guest” when the landing surface is migrated. |
| Success/failure | **Correct** / **Not quite** | The incorrect state must also show or explain the correct answer. |
